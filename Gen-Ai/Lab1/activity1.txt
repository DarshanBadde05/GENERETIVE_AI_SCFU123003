*****MiniMax Music 3******
Who created the model?
  MiniMax
How many parameters does it have?
  2B parameters. It combines an 8B Global LLM, 0.6B Local LLM, 2.4B Flow Matching, and 123M Flow-VAE Decoder.
Is it a generative model?
  Yes. It is a music-generation model that generates complete songs with vocals and music.
What is the context length?
  The tokenized text prompt is limited to 5,000 tokens.
Is the model suitable for local execution?
  Yes. It supports local execution with CUDA and can run with low VRAM using CPU offloading.
What hardware does the model card recommend?
  A GPU with 24GB+ VRAM is recommended. With CPU offloading, it can run on around 22GB VRAM, and with additional layer-by-layer offloading, it can run on an 8GB GPU.
